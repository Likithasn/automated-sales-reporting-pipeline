# sales-dashboard — React Frontend

Place your `sales-dashboard` Vite/React project here (copy your local project folder into `react-dashboard-src/`, replacing this README).

## Suggested structure
```
react-dashboard-src/
├── package.json
├── vite.config.js
├── index.html
└── src/
    ├── components/
    │   ├── SummaryCards.jsx
    │   ├── RegionChart.jsx
    │   ├── RevenueTrendChart.jsx
    │   ├── PipelineStatus.jsx
    │   └── OrdersTable.jsx
    ├── App.jsx
    └── main.jsx
```

## Before committing
- Add a `.env.example` showing the expected API base URL variable (e.g. `VITE_API_BASE_URL=`), and gitignore your real `.env`.
- Do not commit `node_modules/` — it's already in the repo's `.gitignore`.
